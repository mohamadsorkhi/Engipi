# AI_PROJECT_MEMORY.md

## Project

-   Laravel engineering marketplace (existing production project).
-   Development is incremental; no rebuild from scratch.

## Development Workflow

1.  Plan each Sprint.
2.  Split work into Work Packages (WP).
3.  Implement one WP at a time.
4.  Produce a Markdown report.
5.  Human review and approval.
6.  Only then begin the next WP.
7.  No commit, push, or deployment before final approval.
