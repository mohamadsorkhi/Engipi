# EngPis — طرح بلوپرینت (Blueprint)

سه صفحه‌ی آماده، با HTML + CSS + جاوااسکریپت ساده. بدون React، بدون npm، کاملاً آفلاین.

## چطور ببینم؟
فقط فایل را با مرورگر باز کن (دابل‌کلیک):
- `landing.html` — صفحه‌ی اصلی سایت
- `dashboard.html` — داشبورد (اول صفحه‌ی انتخاب نقش؛ روی یک کارت بزن تا وارد شوی)
- `project-new.html` — فرم ثبت پروژه

نیازی به سرور یا لاراول نیست.

## فایل‌ها
- `blueprint.css` — تم مشترک (رنگ‌ها، فونت، دکمه‌ها، کارت‌ها)
- `fonts/` — فونت وزیرمتن + آیکون‌های Remix (خودسرویس، آفلاین)

## رنگ‌ها
- سرمه‌ای `#0E1B2C` · آبی `#1F6FEB` · فیروزه‌ای `#00B8A9`
- فونت: وزیرمتن

## برای انتقال به سایت واقعی (لاراول)
این فایل‌ها طرح بصری هستند. برای اجرا روی engpis.ir باید به Blade تبدیل شوند —
کافی است در چت بگویی تا بسته‌ی آماده‌ی لاراول برایت ساخته شود.
